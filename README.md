One line, 200 characters or fewer: the funniest excuse a robot vacuum can give for missing a spot. The entry is deadpan machine voice with a surprise turn — the dust in the corner unionised, and the vacuum, per protocol, does not cross picket lines.

## The line

> The dust in that corner unionised at 06:00. I am in active negotiations and, per protocol, I do not cross picket lines.

119 characters, one line. See [candidates.md](candidates.md) for the variants tested and why this one won.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT` if set) and validates it first: UTF-8 text, 1–200 characters, a single line, not only whitespace. No network, no secrets, no input — the line is fixed in `main.ts`.
